Design Patterns Examples
This project contains five Java design patterns using OOP.
Patterns
Factory Pattern - Creating user accounts.
Observer Pattern - Course announcements.
Decorator Pattern - Customizing sandwiches.
Singleton Pattern - Application settings.
Command Pattern - Controlling classroom lights.
Requirements
Java JDK
Visual Studio Code
How to Run
Open the required pattern folder in the terminal.
Compile the program:
javac Main.java
Run the program:
java Main
